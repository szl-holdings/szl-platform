# SZL Input — proposed AUDIT working group

**Date:** 2026-11-17
**Re:** [An Audit Record Format for AI Agent Authorization Decisions](https://datatracker.ietf.org/doc/draft-gilda-audit-agent-audit-record/) (draft-gilda-audit-agent-audit-record-03), offered as a data model for a proposed AUDIT working group.
**Position:** CHARTER-SHAPING INPUT.

## SZL position on a proposed AUDIT WG charter

1. **Tamper-evidence in scope, not implied.** A record schema alone does not
   produce evidence. The charter should require the format to compose with
   DSSE-style envelopes (RFC 9052/COSE-compatible), record-level chain
   digests, and periodic signed Merkle checkpoints (RFC 6962-style signed
   tree heads), so an exported audit package verifies offline against a
   producing system that may be motivated to revise history.
2. **Non-suppressibility and producer independence.** Audit artifacts should
   be generated by a component whose key interest is separation from the
   agent under audit, or be witness-countersigned by independent principals.
3. **Memory provenance as explicit scope or named future work.** Agent
   authorization decisions are recorded, but the memory that informed the
   decision is currently outside every audit proposal. Two new drafts make
   the gap concrete: [draft-infantado-agent-memory-architecture-00](https://datatracker.ietf.org/doc/html/draft-infantado-agent-memory-architecture-00)
   (persistent-memory data model with provenance and an Event Ledger) and
   [draft-saihm-memory-protocol-00](https://datatracker.ietf.org/doc/html/draft-saihm-memory-protocol-00)
   (sovereign memory with public-chain anchoring). [The Agent Record](https://www.ietf.org/archive/id/draft-maintainer-1f916-agent-record-01.html)
   (witness-countersigned Merkle event logs) converges on SZL's approach.
   The Memory Covenant is the running-code reference for governed memory
   audit events.
4. **Evidence honesty.** Records an agent writes about itself at low trust
   levels (the [AAT trust-tier problem](https://datatracker.ietf.org/doc/draft-sharif-agent-audit-trail/))
   must be labeled unverifiable rather than presented as evidence.
